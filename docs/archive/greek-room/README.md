# Archive — Greek-room experience

These five documents governed the original MGRT Media homepage: a vaulted stone gallery with a film camera, a monitor and a carved wordmark. They were archived on 2026-10-12 when the Creative Table redesign began on the `redesign/creative-table` branch.

They are kept for two reasons:

- **History.** `build-status.md` is the full change log of that build, and the Greek-room code still exists on this branch until the cutover phase.
- **Measurements.** `technical-architecture.md` §13–§17 holds the complete loading, encoding, viewport and Safari benchmarks. The active `docs/technical-architecture.md` carries the conclusions; the full tables and methods are here.

Nothing in this folder is an instruction for current work. Section references in source comments such as "see `technical-architecture.md` §13" point at these archived files.
